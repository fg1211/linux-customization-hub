# Linux Customization Hub

A curated collection of useful Linux customization projects, tools, and resources.

https://fg1211.github.io/linux-customization-hub/

## Categories

* 🎨 **Themes** — GTK, Hyprland, KDE, terminal and desktop themes
* 🖥️ **GRUB** — GRUB themes and customization
* 📁 **Dotfiles** — Useful dotfiles and configurations
* 🖼️ **Icons & Cursors** — Icon packs, cursor themes and related resources
* 🐧 **Desktop Customization** — Tools for customizing Linux desktops
* 🛠️ **Utilities** — Useful tools for configuring and improving a Linux setup
* 🎨 **Ricing** — Projects and resources for customizing Linux environments

## Website

The collection is available as a GitHub Pages website.

## Contributing

Found a useful Linux customization project?

Feel free to suggest it by opening an issue or submitting a pull request.

Please make sure that suggested projects are relevant to Linux customization, configuration, or improving the Linux desktop experience.
